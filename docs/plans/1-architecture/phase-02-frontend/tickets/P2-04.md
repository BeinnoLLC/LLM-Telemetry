**Phase:** 2 — Presentation  **Complexity:** 🟢 low  **Estimate:** ⏱ 2h
**Status:** not started

## Problem

`build_costs.py` is 557 lines, 43% embedded markup — the same problem as the
dashboard at smaller scale. The costs page is a pure per-1M-token rate
reference, so it is simpler, but it shares the palette and theming contract.

## Change

Apply the pattern proven on the dashboard: `web/costs.html`, shared CSS, shared
palette module. Deliberately sequenced **after** the dashboard so the pattern is
settled rather than invented twice.

Reuse the palette module rather than copying colour logic — the one-colour-per-
model-everywhere contract spans both pages, and a second copy would drift.
