# P1-01 · Version every payload

**Phase:** 1 — Contract  **Complexity:** 🟢 low  **Estimate:** ⏱ 2h
**Status:** not started

## Problem

None of the four payloads (`analytics-data.json`, `live-data.json`,
`ollama-data.json`, `router-data.json`) carries a version field. Verified:

    analytics-data.json  version=MISSING
    live-data.json       version=MISSING
    ollama-data.json     version=MISSING
    router-data.json     version=MISSING

This has already caused two production-shaped failures, both of which rendered a
*plausible but empty* dashboard rather than an error:

1. A sample payload used key `d` where the consumer read `date` — the page
   rendered "0 days · 0 rows" and looked like an empty database.
2. `generated` was written as an epoch int where the consumer called
   `.replace()` on it — the boot screen hung on "LOADING ANALYTICS" forever.

A blank dashboard is indistinguishable from "no traffic yet". That is the
expensive part: the failure is silent.

## Change

Add `schema_version` (integer, starts at 1) to every payload at write time, and
check it at read time.

- Define the constant once in Python (`config.py` or a new `schema.py`) — not
  four copies that can drift.
- The consumer compares against a version it was built for.
- On mismatch: render a visible banner naming both versions and the command to
  re-run the collector. Do **not** fall through to an empty render.
- On a missing field entirely: treat as version 0 and show the same banner.
  Existing payloads on disk predate this change and must not appear to be
  "valid but empty".

## Acceptance

- [ ] All four collectors emit `schema_version`.
- [ ] The version constant is defined in exactly one place in Python.
- [ ] A payload with a wrong version produces a visible, readable error — asserted
      by a jsdom test, not by eye.
- [ ] A payload with no version field produces the same error.
- [ ] The existing 237 checks still pass.

## Notes

The banner text should name the fix (`llm-telemetry analytics`), because the
person seeing it is usually the person who can fix it in one command.
