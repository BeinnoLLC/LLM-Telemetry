# P4-01 · Project key resolver, defined once in Python

**Complexity:** 🟡 medium  **Estimate:** ⏱ 3h  **Depends:** —
**Status:** not started

## Problem

There is no project dimension anywhere in the codebase, and the field the
request assumed — a session *name* — does not exist. Measured on the live
`~/.hermes/state.db` (282 sessions):

| column | non-null | distinct |
|---|---|---|
| `display_name` | 0 | 0 |
| `git_repo_root` | 0 | 0 |
| `git_branch` | 0 | 0 |
| `title` | 43 | 43 |
| `cwd` | 106 | 4 |

`sessions.display_name` is empty in **all 282 rows**, so any code written
against it resolves to nothing. The only usable signal is `title`, and it is a
headline rather than a key:

```
'ahwa-health-gate · Sep 25 12:04'    ← cron; 25 near-identical variants
'ahwa-health-gate · Sep 25 09:05'
'Nowinv'                             ← an actual project
'Ubuntu Diagnosis'                   ← a one-off task
'Explain understand-anything.com and its use in AI code understanding'
```

Grouping on raw `title` gives 43 groups for roughly 12 real projects, because
the cron job embeds a timestamp *inside* the title and fragments into 25
singletons.

## Change

One resolver function, `project_of(session) -> str | None`, defined in exactly
one place (new `projects.py`). Every consumer calls it; no consumer reimplements
the rule.

Resolution order:

1. **`title` stem** — split on the ` · ` separator, take the first segment,
   strip. This collapses the 25 `ahwa-health-gate · <date>` rows into one
   `ahwa-health-gate`. Verified: 25 → 1.
2. **`cwd` basename**, excluding a denylist of non-project roots. Measured, the
   only 4 distinct `cwd` values are `/opt` (101 sessions), `NULL` (176),
   `/home/hazemhagrass/workspace` (3), `/tmp` (1), `/home` (1) — so the denylist
   is `opt`, `tmp`, `home`, `usr`, `var`, `root`, and empty.
3. **`None`** — do not invent a key. An unattributed session is a real, honest
   category and P4-04 gives it a visible bucket.

Normalisation: trim, collapse internal whitespace. Do **not** lowercase —
`Nowinv` should display as the user wrote it. Case-collision handling
(`Workspace` vs `workspace`) is deliberately deferred; see the phase INDEX open
question.

Explicitly out of scope: inferring a project from prompt text, or asking a model
to name it. A guessed label in a cost report is worse than an honest blank.

## Acceptance

- [ ] `project_of()` exists in one module; no second copy of the stem rule.
- [ ] Unit test: the 25 `ahwa-health-gate · <timestamp>` titles resolve to a
      single key.
- [ ] Unit test: `/opt`, `/tmp`, `/home`, `NULL` cwd all resolve to `None`, not
      to `opt`/`tmp`/`home`.
- [ ] Unit test: a session with neither title nor usable cwd returns `None` and
      never raises.
- [ ] Resolver is pure — takes a row, touches no database, no clock, no I/O.
- [ ] The existing 237 checks still pass.
