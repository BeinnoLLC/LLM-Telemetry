# P4-10 · Per-project trend over time

**Complexity:** 🟡 medium  **Estimate:** ⏱ 3h  **Depends:** P4-02
**Status:** not started

## Problem

Distribution is a snapshot. "Is this project's burn accelerating?" needs a time
series, and the payload is already per-date — so the data is there.

## Change

A multi-series line/area chart on the Projects view: one series per project over
the selected date range, driven by the P4-08 weighting.

- Cap to the top N projects by weight, fold the rest into `Other`, and say so in
  the legend. 12+ series is an unreadable chart.
- Stacked-area toggle for "share of total over time".
- Reuse the existing Chart.js setup and theme-aware tick tinting (`tintTicks`)
  rather than a fresh chart config.

## Acceptance

- [ ] One series per project, respecting the active weighting.
- [ ] Top-N cap with an explicit `Other` series.
- [ ] Re-tints correctly on theme switch — the existing `readTheme()` + `render()`
      path must cover it.
- [ ] Legend items toggle series visibility and are keyboard-operable.
- [ ] Renders without overflow at 360px.
