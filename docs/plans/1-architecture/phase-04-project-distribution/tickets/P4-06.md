# P4-06 · Project × provider distribution

**Complexity:** 🟡 medium  **Estimate:** ⏱ 3h  **Depends:** P4-02
**Status:** not started

## Problem

Provider mix per project is the question behind "how exposed is this project to
one vendor?" and "how much of this project is local vs paid?". The data exists
(`billing_provider`, 8 distinct providers observed) but is only aggregated
globally.

## Change

A stacked horizontal bar per project, segmented by provider, on the Projects
view beneath the matrix.

- Reuse the existing provider badge colours and `provIcon()` glyphs — do not
  introduce a second provider palette.
- Normalise-to-100% toggle: absolute answers "where did the money go",
  normalised answers "what is this project's vendor mix". Both are wanted; the
  toggle is one line and the default should be absolute.
- Unknown/blank provider gets the same honest-bucket treatment as P4-04.

## Acceptance

- [ ] One bar per project, segments summing to the project total.
- [ ] Provider colours and icons identical to the Health/Live views.
- [ ] Normalised mode makes every bar equal length; asserted by test.
- [ ] Legend is keyboard-reachable and has a `:focus-visible` ring.
