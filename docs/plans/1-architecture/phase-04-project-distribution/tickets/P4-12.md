# P4-12 · Per-project cost table in `costs.html`

**Complexity:** 🟡 medium  **Estimate:** ⏱ 3h  **Depends:** P4-02
**Status:** not started

## Problem

`costs.html` is the page for money questions, and it has no project dimension —
so the one page a budget conversation would actually open cannot say which
project spent what.

## Change

A per-project cost table on `costs.html`: project, sessions, calls, tokens,
estimated cost, actual cost, share of total.

- Sort by cost descending; Unattributed always rendered, per P4-04.
- Distinguish estimated from actual. `cost_status` and `cost_source` exist
  because some rows are estimates, and silently blending them misstates spend.
- Wide table on a phone needs the horizontal-scroll affordance from #21.

## Acceptance

- [ ] Table renders from the payload with no hardcoded project list.
- [ ] Estimated and actual are separate columns, clearly labelled.
- [ ] Share-of-total column sums to 100% including Unattributed.
- [ ] Table total matches the dashboard's Projects view total — cross-page
      consistency.
- [ ] Scrolls rather than overflows at 360px.
