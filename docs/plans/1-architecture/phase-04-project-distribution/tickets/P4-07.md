# P4-07 · Project drill-down panel

**Complexity:** 🟡 medium  **Estimate:** ⏱ 4h  **Depends:** P4-05
**Status:** not started

## Problem

The matrix shows distribution but not detail. Clicking `Nowinv × opus` should
answer "what actually happened there" without leaving the view.

## Change

A side panel (or bottom sheet on mobile — reuse the P4-11 nav breakpoints and
the logs-drawer pattern from #19) showing for the selected project:

- totals: sessions, calls, tokens in/out, cache read/write, estimated vs actual
  cost
- model breakdown and provider breakdown
- task/tool mix
- the recent sessions belonging to it, with their titles
- first-seen / last-seen dates

## Acceptance

- [ ] Opens from a matrix cell and from a project row label.
- [ ] Closes on Escape and on scrim click; focus returns to the trigger.
- [ ] Panel numbers reconcile with the matrix cell that opened it.
- [ ] On a 360px viewport it is a full-width sheet, not a clipped side panel.
- [ ] Estimated vs actual cost are labelled distinctly — conflating them is a
      money bug, and `cost_status`/`cost_source` exist precisely because some
      rows are estimates.
