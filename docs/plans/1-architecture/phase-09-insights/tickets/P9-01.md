# P9-01 · Brand the header: logo before the title, and a favicon

**Phase 9 — Brand, transcript preview, and unused-signal panels** · ticket `P9-01` · complexity 🟢 low · est ⏱ 2h · depends: -

## Finding first: the rename is already done

The request was to change the page title from "Model Router Analytics" to
"LLM Telemetry". **That string does not exist in the repo.** Verified:

    grep -rn "Model Router\|Router Analytics" --include=*.py --include=*.js .
    (no matches)

`build_dashboard.py:30`  ->  `<title>LLM Telemetry</title>`
`build_dashboard.py:562` ->  visible `.page-title` div reads `LLM Telemetry`

Commit `17fea48` ("Rename product to LLM Telemetry") already did it. If you are
still seeing the old name, it is a **stale built HTML file** being served, not a
source problem — rebuild with `llm-telemetry dashboard`.

So this ticket is only the part that is genuinely missing: **there is no logo and
no favicon.**

## What is missing

1. No logo anywhere. The header is a bare text div.
2. No favicon: `grep -c "favicon"` finds one `<link rel>` line, and it is not an
   icon. The browser tab shows a blank page glyph.
3. `costs.html` has a different brand treatment (`<h1>Model price sheet</h1>`),
   so the two pages do not look related.

## Change

- Add an inline SVG logo immediately before the title text in the header, sized
  to the title (`clamp(16px,2.5vw,22px)` line box) so it scales with it.
- Inline SVG, **not** an external file: the dashboard is a single
  self-contained HTML artifact (ADR 0001). A `<img src>` would break the
  file-copy-and-open workflow and add a request the static server cannot cache.
- Add the same mark as a `<link rel="icon">` data URI so the tab is branded.
- Apply the same lockup to `costs.html`, so both pages read as one product.
- The mark must work on both themes: `currentColor` or a theme-aware CSS var,
  never a hardcoded hex that vanishes on the light theme.

## Acceptance

- [ ] Logo renders immediately before the title in the dashboard header.
- [ ] Logo is inline SVG; no new network request, page still opens from `file://`.
- [ ] Favicon renders in the browser tab.
- [ ] Logo visible and legible on BOTH dark and light themes (assert computed
      fill/stroke is not equal to the card background in either theme).
- [ ] `costs.html` carries the same lockup.
- [ ] Logo has `aria-hidden="true"` (decorative; the title next to it is the
      accessible name) or an explicit `<title>` element inside the SVG.
- [ ] Header does not wrap or overflow at 360px.

## Notes

No logo asset exists in the repo (`find -iname "*logo*" -o -iname "*.svg"`
returns nothing). Either the owner supplies the mark, or this ticket includes
drawing a simple one. Flagging rather than inventing brand identity.
